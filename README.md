# Портал «Music Box»

Вёрстка (без JS) музыкального портала: главная страница и страница
артиста, позиционирование по макету Figma.

## Стек

HTML, SASS (переменные, шрифты Roboto через `@font-face`), без
CSS-фреймворка. `htmlhint`/`stylelint` — линтеры (см.
`.htmlhintrc.json`/`.stylelintrc.json`).

## Текущее состояние: вёрстка не написана

`src/index.html` и `src/artist.html` существуют, но их `<body>` пуст —
только базовый `style.css` (шрифты, цвета, заголовки) и полный набор
изображений/шрифтов, но ни один блок макета не свёрстан.

**Проверено 2026-09-01: `hexlet-check` для этого типа проекта — НЕ только
структура репозитория, как показалось на первый взгляд.** Он гоняет
Playwright-тест (`__tests__/ui.spec.js`, 21 тест) с попиксельным
сравнением скриншотов каждой секции (`#page-description`,
`#page-pricing`, `#page-news`, `#page-app` на главной;
`#page-description`, `#page-popular-track`, `#page-discography`,
`#page-similar` — да, на странице артиста есть блок «Похожие
исполнители», в тексте шагов явно не описанный отдельно — на артиста)
плюс футера и обеих страниц целиком, для десктопа (1440×900) и мобильной
версии (414×896). При пустом `<body>` он падает на первом же тесте.
Эталонные скриншоты скачаны из артефакта упавшего прогона
(`gh run download <run-id>`) — там же лежит `playwright.config.js`
харнесса. Судя по истории прогонов (зелёный 2026-08-22 на том же пустом
`<body>`), этот тест тоже появился недавно — старый green был получен
проверкой, которая контент не смотрела.

Полный текст всех 10 шагов (структура, отступы, размеры, цвета,
разбивка на компоненты для каждой секции) получен через API проекта
(`/projects/56/members/42880?step=N`) — там же ссылка на Figma-макет.
Ни макет, ни текст шагов не скопированы в этот README — это чужой
контент (доступ только по логину), сверяться с ним нужно живьём на
странице проекта. Эталонные скриншоты из артефакта CI дают точный
визуальный ориентир без Figma.
